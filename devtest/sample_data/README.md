# Sample data

The catalogue the seed of devtest (`../seed.py`) loads into an empty
database, and the sheets the order import is tried with. Everything here is
generated by `fetch_openlibrary.py` and committed: rebuilding the database
needs no network.

| File | What it holds |
|---|---|
| `books.csv` | One real edition per book: its title in the edition's language, the work's title when it differs (`original_title`), ISBN-13, edition date, year of the work (`first_published`), pages, publisher, genre tags, author ids, the Open Library cover id |
| `authors.csv` | Name, birth and death date, nationality, the Wikidata id |
| `publishers.csv` | The publishers the editions name, joined across spellings |
| `purchase_orders.xlsx` | Our layout: `order` groups the rows into documents (two orders), `publisher` by name, `title` only for whoever reads the sheet |
| `purchase_orders_errors.xlsx` | The same layout with one mistake of each kind: an ISBN nobody has, a quantity in words, an ISBN two books share, a misspelt publisher, a discount over 100 |
| `publisher_order.xlsx` | A publisher's own order form: its column names (`EAN`, `Qty`, `Disc.`), the discount as text, a column we do not use, no publisher column. Our layout refuses it at the header; a derived plugin reads it |

## Where it comes from

Books are chosen from the [Open Library](https://openlibrary.org) search: a
fixed list of subjects (the genre of the book), a quota per language (English,
Italian, French, German, Spanish), the most read first, plus a few books each
of a list of Italian writers. A book is kept only when the search's edition is
in that language, has an ISBN-13 and names a real publisher (print on demand
is skipped). Authors take dates and nationality from
[Wikidata](https://www.wikidata.org), found through their Open Library id.

The data is bibliographic: Open Library asserts no rights over it, Wikidata is
CC0. Prices are invented, the same for the same ISBN on every run. Biographies
and descriptions are left out on purpose: they are looked up on demand, by the
Wikidata id and by the ISBN.

One pair of books shares an ISBN on purpose, a reprint recorded with the
number of its first printing (`... (reprint)`): the order import has to meet it.

## Making it again

From `devtest/`:

```bash
uv run python sample_data/fetch_openlibrary.py            # CSV and sheets
uv run python sample_data/fetch_openlibrary.py --sheets   # the sheets only, from the CSV
uv run python sample_data/fetch_openlibrary.py --covers   # covers into media/books/covers/
rm devtest.sqlite && uv run devtest.py                    # rebuild the database
```

The answers of Open Library and Wikidata are cached in `_cache/` (not in git):
a second run asks only for what the lists in the script changed. Delete the
folder to see what the sources say today; the catalogue then changes with them.

Covers are not in git. Once downloaded they stay in `media/books/covers/`, and
on every start the seed links them to the books that have no cover yet: a
download after the database was made needs only a restart.
