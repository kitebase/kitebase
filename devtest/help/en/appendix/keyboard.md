# Keyboard shortcuts

| Key | Where | What it does |
|---|---|---|
| F1 | on a field | its help, or the guide on that field when it has none |
| F1 | anywhere else | the guide of the page you are on |
| F12 or Ctrl+Enter | in a form | saves, or goes to the next step |
| Esc | with a help or a list open | closes it |
| Enter | in the search box of a list | runs the search |
| Arrows and Enter | in a list of choices | pick an entry |

*Search more...*, at the end of a list of choices, opens the whole table to
pick from. The Back button of the browser closes the page on top.
